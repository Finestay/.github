# Contribuer à Finestay

## Créer une issue

Avant de commencer, recherchez les issues existantes. Choisissez **Rapport de bug** pour un dysfonctionnement ou **Demande de fonctionnalité** pour une évolution. Remplissez chaque section utile, en particulier les étapes de reproduction ou les critères d'acceptation.

## Créer une pull request

1. Créez une branche courte et descriptive depuis la branche cible.
2. Ouvrez une issue pour les changements non triviaux, puis liez-la dans la pull request avec `Closes #<numéro>`.
3. Ouvrez la pull request et complétez le modèle : résumé, validation, captures si l'interface change et checklist.
4. Attendez une CI verte et une relecture avant de fusionner. Ne fusionnez pas votre propre pull request sans validation de l'équipe.

Ne placez jamais de mot de passe, clé API ou donnée personnelle dans une issue, une pull request ou des logs.
